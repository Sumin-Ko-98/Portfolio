# Sumin Ko — Portfolio

제품디자이너 고수민의 포트폴리오 사이트입니다. 정적 HTML · CSS · JS로 만들었고, GitHub Pages가 `main` 브랜치 루트를 그대로 배포합니다.

- 라이브: https://sumin-ko-98.github.io/Portfolio/
- 작업 방법 · 사실 기준 · 남은 일: [`_tools/인수인계.md`](_tools/인수인계.md)
- 상세페이지(`work/*.html`)는 `_tools/story_pages.py`를 고친 뒤 `python _tools/gen_story.py`로 생성합니다. 직접 고치면 덮어써집니다.
- 공유 미리보기 이미지 · 파비콘: `python _tools/make_meta_assets.py`
- 로컬 미리보기: `python -m http.server 8780` → http://127.0.0.1:8780
