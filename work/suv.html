Overview

플래그십 세단이 고요함을 재발명하다.

본 프로젝트에서는 프리미엄 세단의 실내 인터랙션을 재정의하기 위해 필드 리서치, 심층 인터뷰, 아이데이션 워크숍을 진행하고, 우선순위가 높은 사용자 경험 항목을 셀렉트했습니다.

결과물은 브랜드 담당자에게 UX 컨셉 솔루션으로 전달되어, 다음 세대 세단의 실내 사용성 개선에 참고 자료로 활용되었습니다.

Feature Framing
4가지 인터랙션은 “정지 → 승차 → 주행 → 하차”의 완전한 여정 위에 배치되어, 각 순간이 어떤 경험을 제공하는지를 클라이언트 브리핑 자료로 명확히 시각화했습니다.
Fig. 06 · Journey Map Park · Board ·
Drive · Exit 승·하차부터 후석 확장 경험까지의 Passenger Journey를 4단계로 나누어, 각 단계별 인터랙션 우선순위를 산출했습니다.
Key Interactions

  1. Interior Custom Mode

    탑승자 프로필에 따라 시트, 조명, 향기, 사운드가 자동 세팅.

  2. Center Console

    확장형 센터콘솔로 후석 승객과의 공유 공간을 재설계.

  3. Cup Holder & Table

    주행 상황에 맞춰 접히고 펼쳐지는 컵홀더·테이블 매커니즘.

  4. Trunk Luggage-box

    세단이지만 캠프 모드처럼 열리는 트렁크 러기지박스.
