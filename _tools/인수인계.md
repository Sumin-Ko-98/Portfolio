- `work/threespin.html` 등 7개는 **`_tools/pages.py`를 고친 뒤** `python _tools/gen_pages.py` 로 다시 만든다(직접 고치면 덮어써짐). pymupdf 필요(`pip install pymupdf`).

- `work/wade.html`은 디자인이 달라서 직접 고친다.
