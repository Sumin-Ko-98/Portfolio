## 2. 상세페이지 = Story 레이아웃

사용자가 "정돈됐다"고 한 원래 WADE 상세(2026.09)의 리듬을 8개 페이지 공통으로 씀:
머리 → 16:9 히어로 → 정보 줄 → 수상/요점 + 한·영 소개 → **블랙 패널**(와이드 이미지 · MARK 문단 · 원형 이미지 3 · MARK 문단 · 와이드 이미지) → 풀블리드 장면 → **화이트**(라벨 문단 ↔ 정사각·3열·2칸·풀블리드 이미지 교차) → **블랙 패널**(공정 6컷 · 문단 · 수치 · ROLE) → 마지막 풀블리드 → 검은 띠 → 이전/다음.

- 고치는 법: `_tools/story_pages.py` 수정 → 레포 루트에서 `python _tools/gen_story.py` (한 페이지만: `python _tools/gen_story.py ts700`). work/*.html 직접 수정 금지(덮어써짐). pymupdf 필요.
- 이미지: 섹션에 파일명만 쓰면 `assets/works/<dir>/`에서 찾고, 없으면 `SOURCES`의 원본에서 자동 변환. 제품 렌더처럼 잘리면 안 되는 건 `{"f": ..., "fit": "contain", "bg": "#fff"}`, 원래 비율 그대로는 `"r": "natural"`(정사각·세로 사진엔 쓰지 말 것 — 화면보다 커짐), 크롭 위치는 `"pos": "50% 30%"`.
- 제품 렌더는 칸에 맞춰 자르지 말고 `{"f": ..., "fit": "contain", "bg": "auto", "pad": "8%"}` — `bg: "auto"`는 이미지 왼쪽 위 픽셀 색으로 판을 칠해 회색 띠가 안 생김, `pad`는 제품이 가장자리에 붙지 않게.
- `SOURCES` 값은 경로 대신 dict도 됨: `{"src": 경로, "rot": 270}`(EXIF 회전 반영, pymupdf는 반시계라 시계 90°=270), `{"src": 경로, "crop": (x0,y0,x1,y1) 비율}`, `{"pdf": 경로, "page": 6, "rect": (...), "scale": 2}`(최종 PDF 7쪽 Before/After 주석 컷). `FINAL_PDF`는 이 세션 임시 폴더 사본이라, 다시 만들 땐 `Downloads\고수민_포트폴리오.pdf`로 바꿀 것.
- 표지: LS의 `cover.jpg`는 왼쪽을 블러로 확장한 이미지라 이음매가 보임 → 반드시 `cover_src.jpg`(원본) 사용.
- 한 페이지 안에 같은 사진·거의 같은 컷을 두 번 쓰지 말 것(리뷰 지적 사항).
- **흰 구간 읽기 순서 = 사진 → 그 사진의 설명**(2026-10-14 사용자 지적). `story_pages.py`에는 지금처럼 `("text", …)` 다음에 그 사진들을 적으면 되고, 생성기 `caption_after_images()`가 사진을 설명 앞으로 옮김(split 짝·single 포함). CSS `.wd-textrow`의 위 여백이 좁고 아래가 넓은 것도 이 순서 전제. 설명에 "아래/위 사진" 같은 위치 표현을 쓰면 위 = 사진.
- **홈·Work 카드 썸네일 = `assets/cards/<slug>.jpg`**(1200×900, 2026-10-14). `python _tools/make_cards.py`로 생성. 최종 PDF 표지와 같은 대표 컷을 제품 중앙·같은 비율로 맞춤(제품 bbox는 스크립트에 지정, 장면 컷은 꽉 채움, CMF는 2×2). 카드 `<img>`에 `object-position`·`style` 개별 지정 금지, 카드를 2칸으로 키우는 강조 레이아웃도 쓰지 않음(제품이 작아지고 잘림). 홈 Product는 6장(3×2).
- HEIC 실물 사진: `SOURCES`의 HEIC 경로는 이번 세션 임시 폴더(변환본)라 이미 assets에 있음. 새 HEIC는 WIC로 변환(PowerShell `Windows.Media.Imaging.BitmapDecoder`, HEIF 확장 설치돼 있음).
- 미리보기: 레포 폴더에서 `python -m http.server 8780` → http://127.0.0.1:8780 (전체 캡처는 `?static`). 8765는 인스타 오늘뭐봄 프로젝트가 쓰므로 피할 것
